# 📝 Notes App (SQL + Swagger)

A full-featured CRUD (Create, Read, Update, Delete) Notes application built with SQL as the database and tested via Swagger UI.

---

## 🚀 Features

- Add, view, update, and delete notes
- SQL database integration (e.g., MySQL)
- Interactive Swagger API documentation
- RESTful architecture

---

## 📦 Tech Stack

- **Backend**: .net + JavaScript frontend
- **Database**: SQL (MySQL )
- **Docs**: Swagger (OpenAPI 3.0)

---
